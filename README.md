# learning

学習したいテーマに沿って、小さなコンソールアプリを作って試すためのリポジトリ。

## 見方

ディレクトリ = 学習テーマ単位。各テーマについて「学びたかったこと」「試したこと・気づき」を書いている。コードそのものより、何を確かめるための実験だったかを追えるようにすることを目的にしている。

## ディレクトリ一覧

### `dotnet/httpclient/handler-pipeline/`

HttpClient の DelegatingHandler パイプライン

- 学びたかったこと: `DelegatingHandler` を重ねてリクエストパイプラインを組んだとき、直列化やリトライ制御をどう挟み込めるか
- 試したこと・気づき: `ThrottlingHandler`（`SemaphoreSlim` でリクエストを直列化）が `FakePrimaryHandler`（初回だけ 429、以降は 200 を返すフェイク）をラップする構成を作り、3回連続リクエストしてステータスコードの変化を確認した。Polly を本格的に組み込む前の素振りという位置づけ

### `dotnet/transaction-lab/`

サービスをまたいだトランザクション境界

- 学びたかったこと: 複数のサービス呼び出し（注文作成 → 決済作成）を1つのトランザクションとして扱うには何が必要か
- 試したこと・気づき: `OrderService.CreateOrder()` の後に `PaymentService.CreatePayment()`（わざと例外を投げる）を呼び、失敗時に注文もロールバックされるかを検証。`SqliteTransaction` を各サービスに明示的に渡す方式と `TransactionScope` を使う方式を見比べ、前者は「トランザクション管理がサービスAPIに漏れ出す」というトレードオフがあることに気づいた

## 新しいテーマを追加するとき

以下の3行フォーマットで追記する。

```
### `path/to/dir/`

テーマの一言タイトル

- 学びたかったこと: ...
- 試したこと・気づき: ...
```
